## JavaScript กับ Java ภาษาเดียวกันไหม?

- **คือคนละภาษาโปรแกรมนะครับ**

## javaScript คืออะไร?

- **ภาษาโปรแกรมที่ใช้ในการพัฒนาเว็บและแอปพลิเคชันที่ทำงานในส่วนของ Client-side หรือ Server-side ภาษานี้ถูกสร้างขึ้นโดย Netscape และเปิดตัวครั้งแรกใน Netscape Navigator 2.0 เมื่อปี 1995 โดยนาย Brendan Eich**

## Client-side หรือ Server-side  คืออะไร ?

- **Client-side ในบริบทของเว็บ, ไคลเอ็นต์ (หรือ client-side) หมายถึงส่วนของโปรแกรมที่ทำงานบนเครื่องผู้ใช้ (เว็บเบราว์เซอร์) และมีหน้าที่แสดงผล, รับข้อมูลจากผู้ใช้, และประมวลผลข้อมูลในฝั่งของผู้ใช้**
- **Server-side ในบริบทของเว็บ, เซิร์ฟเวอร์ (หรือ server-side) หมายถึงส่วนของโปรแกรมที่ทำงานบนเซิร์ฟเวอร์ และมีหน้าที่ประมวลผลข้อมูล, จัดเก็บข้อมูล, หรือทำงานที่ไม่ต้องการผู้ใช้งานเข้ามาเกี่ยวข้องโดยตรง.**
